# 📦 Campus Delivery

## Breve descrição do projeto
O Campus Delivery é um aplicativo de entregas internas para a faculdade. Ele conecta alunos que vendem lanches e materiais com estudantes que precisam comprar esses itens, mas não podem sair de suas salas de aula. 

## Objetivo
Facilitar a compra e venda de produtos dentro do ambiente acadêmico, permitindo que a entrega seja feita diretamente na sala de aula do comprador, otimizando o tempo de todos.

## Público-alvo
Estudantes, professores e funcionários da faculdade.

## Funcionalidades
- Catálogo virtual de produtos anunciados pelos alunos.
- Sistema de compra com indicação exata do bloco e sala para entrega.
- Acompanhamento do status do pedido (preparando, a caminho, entregue).

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Como executar
1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no seu navegador de preferência.
